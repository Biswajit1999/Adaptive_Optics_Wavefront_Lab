# Adaptive Optics Science Validation Contract

This repository is a teaching laboratory for adaptive-optics wavefront correction. Visual panels must remain tied to the equations below and must not add decorative effects that look like measured data, turbulence, or detector physics.

## Validated physical assumptions

### Pupil-plane phase model

The wavefront is represented as a low-order sum of approximately RMS-normalised Zernike modes on a unit circular pupil:

```text
W(x, y) = sum a_i Z_i(x, y)
```

The coefficients are in waves. The browser complex pupil is therefore:

```text
E(x, y) = P(x, y) exp(i 2 pi W(x, y))
```

where `P(x, y)` is a binary pupil mask.

### Ideal modal correction

The modal controller is intentionally idealised:

```text
W_residual = (1 - gain) W
```

For this simplified model, gain must remain in the stable teaching interval:

```text
0 <= gain <= 1
```

A gain of zero leaves the modal phase unchanged. A gain of one removes the represented modal phase exactly. This does not model closed-loop latency, deformable-mirror influence functions, WFS noise propagation, saturation, or non-common-path errors.

### Fourier optics convention

The monochromatic focal-plane diagnostic is computed from the sampled complex pupil:

```text
PSF = |FFT(E)|^2
```

Under the discrete Fourier transform convention used here, Parseval energy conservation should hold after the corresponding `N^2` normalization.

### Strehl diagnostic boundary

The compact Strehl-like budget uses the low-aberration Marechal approximation:

```text
S ~= exp[-(2 pi sigma)^2]
```

This is a small-phase diagnostic. It must not be described as a calibrated Strehl prediction for large aberrations or real observatory operations.

## Validation checks added in this branch

`tools/validate_optics_contract.py` independently checks:

1. Low-order Zernike modes have near-zero piston on the sampled pupil.
2. Supported modes remain approximately unit RMS.
3. Different supported modes are approximately orthogonal on the common sampling grid.
4. Half modal gain halves residual modal RMS.
5. Gain outside the stable teaching interval is rejected.
6. The discrete Fourier transform obeys Parseval energy conservation for a phase-only field.

## Reproducibility commands

Run all current scientific checks with:

```bash
python tools/validate_model.py
python tools/validate_optics_contract.py
node tools/validate_fourier_psf.js
```

## Interface constraints

Allowed interface improvements:

- clearer labels for phase, pupil mask, PSF, and MTF panels;
- unit annotations for waves, pupil radius, and normalized spatial frequency;
- visual changes that expose existing computed quantities more truthfully.

Disallowed interface changes:

- decorative speckles, glow, turbulence, lens flare, or noise that is not generated by the model;
- animation that implies real closed-loop temporal evolution unless a validated time-domain model is added;
- colour maps or transitions that imply extra physical measurements.

## Next scientific gap

The next defensible upgrade is a Shack-Hartmann or curvature-sensor measurement module. It should be added only with tests for local wavefront-slope sign convention, spot displacement scaling, sensor sampling limits, and noise units.
